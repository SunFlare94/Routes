SYSTEM REQUIREMENTS
-------------------
- Windows 10 or later (64-bit)
- OpenGL 4.0+ compatible GPU with updated drivers
- No additional software needed — everything is bundled


HOW TO PLACE MAP FILES
----------------------
1. Download .obf map files from https://osmand.net/
   Or export them from the OsmAnd mobile app

2. Place the .obf files in the "obf files" folder next to Routes.exe

3. Multiple map files can be loaded at once
   The app auto-detects all .obf files in the folder


HOW TO USE
----------
1. Double-click Routes.exe
2. The map loads automatically from the obf files folder
3. Use your mouse to navigate the map


CONTROLS
--------
  Mouse wheel        Zoom in / out
  Left-click drag    Pan the map
  Right-click drag   Rotate the map
  M key              Start distance measurement tool
  N key              Toggle night mode (dark map)
  R key              Reset rotation to north
  Esc                Exit distance tool / clear points
