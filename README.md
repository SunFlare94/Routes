# Routes — Desktop Offline Map Viewer

A Windows desktop offline map viewer with route planning and navigation support.

**Developed by Mukul Pramanik (SunFlare94)**

---

## Download

Download **Routes.exe** directly from this repository:

**[Download Routes.exe](./Routes.exe)**

Routes includes a **10-day free trial** so you can try the application before purchasing a license.

After the trial expires, a valid license key is required to continue using Routes.

---

## Features

- Offline map viewing
- Route planning
- Map navigation
- Support for `.obf` map files
- Automatically detects `.obf` files from the `obf files` folder
- Multiple map files can be loaded at the same time
- Dark map mode
- Zoom and pan controls
- Distance measurement
- Point marking
- Map rotation
- Reset map view
- Built-in license system
- Machine-specific license keys

---

## System Requirements

- **Windows 10 or later (64-bit)**
- **OpenGL 4.0+ compatible GPU**
- Updated graphics drivers
- No additional software installation required — everything needed is bundled with the application

---

## Map Files

Routes uses **OsmAnd `.obf` map files**.

### How to Get Map Files

1. Download `.obf` map files from:
   **https://download.osmand.net/**
2. You can also export map data from the OsmAnd mobile application.
3. Create or open the `obf files` folder next to `Routes.exe`.
4. Place your `.obf` map files inside the `obf files` folder.
5. Launch `Routes.exe`.

Routes will automatically detect the `.obf` files in the folder.

### Multiple Maps

You can place multiple `.obf` map files in the `obf files` folder.

Routes can automatically detect and load the available map files.

---

## How to Use

1. Double-click **Routes.exe**.
2. The application automatically loads the available maps from the `obf files` folder.
3. Use your mouse to navigate the map.

---

## Controls

| Action | Control |
|---|---|
| Zoom | Mouse wheel |
| Pan | Left-click and drag |
| Rotate map | Right-click and drag |
| Distance measurement | `M` key |
| Toggle dark map mode | `K` key |
| Reset rotation | `R` key |
| Reset map view | `K` key |
| Exit distance tool | `Esc` key |
| Clear marked points | `Delete` key |
